# 온빌딩 매출·수수료 관리

입점업체의 오프라인 POS 및 온라인·라이브 판매를 한 화면에서 집계하고, 거래별 수수료와 카드·PG 정산 예정액 및 실제 입금액을 대조하기 위한 운영 화면 초안입니다.

## 실행

정적 파일인 `index.html`을 브라우저에서 열면 됩니다. 별도 패키지 설치는 필요하지 않습니다.

## 데모 기능

- 통합 매출 대시보드와 채널별 집계
- 입점업체 및 판매 채널 등록·수정
- 주문 단위 매출 입력과 환불 반영
- 매출 CSV 가져오기·내보내기
- 주문번호 기준 은행·PG 입금 CSV 대사
- 업체별 수수료율과 부가세 별도 정산서 계산
- JSON 데이터 백업

데모 데이터는 브라우저의 `localStorage`에 저장됩니다. 브라우저나 기기를 공유해도 자료가 동기화되지 않으며, 인증·권한관리·감사로그·서버 백업이 없습니다. 실제 계약 또는 세무 정산에 바로 사용하지 마세요.

## 매출 CSV 열

`order_id,date,tenant,channel,product,gross_amount,discount,refund,status,payment_method,payout_expected,payout_received`

금액은 원 단위 숫자로 입력합니다. 은행·PG CSV에는 `order_id`와 `payout_received` 또는 `amount` 열을 사용합니다.

## 데모 수수료 산식

현재 화면은 확정 매출액에서 할인·환불을 반영한 뒤, 부가세 포함 가격을 1.1로 나눈 값을 수수료 대상 공급가액으로 보고 업체별 수수료율을 적용합니다. 수수료 부가세 10%는 별도 계산합니다. 실제로는 공급계약에 정한 과세 유형, 할인 부담자, 배송비, 환불 확정 기준과 정산 주기에 맞춰 확정해야 합니다.

## 운영 버전에서 연결할 항목

1. 인증·역할권한(건물 관리자, 정산 담당자, 입점업체)
2. 서버 DB와 변경 불가 거래 원장, 취소·수정 역분개, 작업자 감사로그
3. POS/카드 VAN 거래 및 카드사 입금 대사
4. 채널별 주문·환불 API 또는 승인된 정기 자료 수집
5. PG·은행 거래 자료 업로드와 거래번호·금액·일자 매칭
6. 정산 마감, 업체 확인, 이의제기, 세금계산서 발행 연계
7. 암호화·백업·보존기간·개인정보 접근 통제

온라인 채널의 API 제공 여부와 데이터 범위는 플랫폼마다 다릅니다. 실제 자동연동은 입점업체 권한과 공식 API 승인 범위를 확인한 뒤 진행해야 합니다.
