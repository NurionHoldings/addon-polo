# POS·판매채널·PG·은행 커넥터 업체 협의 양식

이 양식은 업체 담당자에게 질문을 빠뜨리지 않도록 준비한 것입니다. 업체별 API와 인증이 다르므로 답변을 받은 뒤 실제 연동을 활성화합니다. 계정 비밀번호, API 비밀키, 고객 개인정보를 이메일·문서·이슈에 붙여넣지 마세요.

## 미팅에서 확인할 항목

### 1. 제공 범위와 계약

- [ ] 어떤 계약자/계정이 API 또는 파일 제공을 신청해야 합니까?
- [ ] 건물 운영자가 입점업체별 매출·정산 정보를 대신 조회할 수 있습니까? 업체별 동의가 필요합니까?
- [ ] 운영/재무 목적의 조회 권한이 약관과 계약에서 허용됩니까?
- [ ] 개발자 문서 URL, 데이터 이용·보관 기간, 비용과 지원 담당자는 누구입니까?

### 2. 데이터 내용

- [ ] 매출을 결제완료, 배송완료, 구매확정 중 어떤 기준으로 제공합니까?
- [ ] 주문 ID와 각 결제/취소/환불 건마다 변하지 않는 고유 ID가 있습니까?
- [ ] 전체 취소와 부분 환불, 재승인, 교환을 어떻게 표현합니까?
- [ ] 할인 후 고객 실결제액, 할인 부담 주체, 상품 공급가액, 부가세를 각각 받을 수 있습니까?
- [ ] 정산 참조번호, 예정 지급액, 결제 수수료, 지급예정일을 제공합니까?
- [ ] 은행은 입금 거래 고유번호, 날짜, 입금액만 읽는 권한을 지원합니까?
- [ ] 개인정보를 빼도 대사와 수수료 계산에 필요한가요? 불필요한 고객 이름·전화번호·주소는 받지 않습니다.

### 3. 기술 연결

- [ ] 실시간 웹훅, 주기적 API 조회, CSV 중 어떤 방식을 지원합니까?
- [ ] 샌드박스 계정과 가짜 주문·환불·정산 표본을 제공합니까?
- [ ] 인증은 OAuth2, 인증서, HMAC 서명 중 무엇이며 만료·갱신은 어떻게 합니까?
- [ ] 서명 대상 원문, 서명 헤더, 타임스탬프 허용시간, 재전송 식별 방법을 문서로 받을 수 있습니까?
- [ ] 조회 기간 제한, 페이지 방식, 호출량 제한, 지연 반영시간, 오류별 재시도 규칙은 무엇입니까?
- [ ] 과거 자료를 몇 개월까지 조회할 수 있습니까? 같은 자료를 다시 받아도 고유 ID가 유지됩니까?
- [ ] 서비스 점검·장애 공지와 API 버전 변경 사전 안내를 받을 수 있습니까?

### 4. 실운영 승인

- [ ] 업체·입점업체 운영 책임자와 회계 담당자가 필드 정의 및 수수료 계산을 확인했습니까?
- [ ] 샌드박스 매출, 부분환불, 취소, 중복 수신, 재시도, 페이지 경계 테스트를 통과했습니까?
- [ ] 과거 기간 합계와 새 연결 자료를 CSV/화면/업체 원본에서 표본 대조했습니까?
- [ ] 어느 날짜부터 자동 자료를 기준으로 삼을지, CSV와 중복 기간이 겹치면 어떻게 처리할지 정했습니까?
- [ ] 수집 중단 담당자와 수동 CSV 대체 절차를 정했습니까?

## 업체에 요청할 표본 자료

고객 실명·연락처·주소를 지운 상태로 아래 경우를 하나씩 요청합니다.

1. 정상 매출 1건, 할인 적용 매출 1건
2. 전체 취소 1건, 부분 환불 1건, 환불 후 재정산 1건
3. 여러 주문이 한 정산으로 합쳐진 사례 1건
4. PG 정산액과 은행 입금액이 일치하는 사례 및 차이 나는 사례
5. 같은 주문을 API 페이지/웹훅 재전송으로 두 번 받는 사례

## 협의 결과를 구현 정보로 옮기는 법

1. 공식 문서·필드사전·샌드박스 예제를 버전과 받은 날짜와 함께 기록합니다.
2. `provider-map.template.json`을 복사해 업체 필드 경로와 상태값을 매핑합니다.
3. 업체 거래 고유번호가 `event_id`로 보존되는지 확인합니다. 고유 ID가 없으면 복합키 설계를 검토하고 업체 담당자 승인을 받습니다.
4. 앱에 쓰기 전에 정규화 도구를 샘플 자료에 실행해 canonical CSV로 변환합니다.
5. 샌드박스·중복·환불·타임아웃 테스트와 원본 대조를 통과한 뒤에만 운영 환경에 비밀키를 등록합니다.
6. 운영 전환은 담당자가 승인하고, 첫 정산 주기는 원본과 병행 대조합니다.

## 현재 구성 상태

| 연결 구간 | 지금 가능한 방법 | 업체 협의 후 추가할 것 |
|---|---|---|
| POS/VAN 매출 | 직접 입력·CSV | POS별 공식 조회 또는 이벤트 어댑터 |
| 온라인·라이브 판매 | 직접 입력·CSV | 채널별 승인 API/웹훅·상태 매핑 |
| PG·카드 정산 | 정산 묶음 CSV | 정산 API와 수수료·지급 규칙 |
| 은행 입금 | 입금 포함 CSV | 계좌주 동의 기반 읽기 전용 거래 조회 |

현재 앱에는 API 자동수집이 연결되어 있지 않습니다. 업체명이 정해지고 문서·샌드박스·동의 권한을 받으면 이 양식과 JSON 매핑을 바탕으로 업체별 어댑터를 구현할 수 있습니다. 비밀키는 앱 DB나 Git에 저장하지 않고 배포 환경의 Secret Manager/환경변수로 주입합니다.
